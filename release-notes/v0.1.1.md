## 中文

- 新增「帮助」菜单，集中提供使用帮助、快捷键、检查更新和「关于 RedisPal」。
- 界面字体改为下拉选择，支持系统默认和常用 Windows 字体，并兼容已保存的自定义字体。
- 将版本和更新信息移到「帮助」，简化首页。侧栏、首页和「关于」窗口的 Logo 四角更圆润。

## English

- Added a Help menu with the user guide, keyboard shortcuts, updates, and About RedisPal.
- Replaced the font text field with a dropdown of common Windows fonts and a system default. Existing custom font preferences are supported.
- Moved version and update information to Help and rounded the logo corners in the sidebar, home screen, and About dialog.
